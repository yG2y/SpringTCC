\section{Pacote de Replicação}
\label{sec:replicacao}

O pacote de replicação deste trabalho reúne a base de descoberta (\texttt{population.csv}), os \emph{scripts} das seis etapas do pipeline oficial (\texttt{pipeline\_oficial\_tcc/}), os arquivos CSV de candidatos, curadoria, \emph{snapshots} CK e detecção de IA, os manifestos JSON com parâmetros e \emph{hashes} SHA-256 e o gerador determinístico das tabelas LaTeX, estando disponível em: \repositorioTCC.
